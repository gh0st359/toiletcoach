# ToiletCoach

A professionally polished joke: an AI companion that coaches people through shitting, pissing, farting, sharting, and related emergencies.

Installable as a mobile-first PWA. Coach Flush is vulgar on purpose, useful on accident, and very clear that this is not medical advice.

## Features

- Onboarding with filthy or clinical voice
- Home clinic: streak, hydration, fiber, live session, quick actions
- Coach chat with tools (start sit, Bristol, breathing, push protocol, fart analysis, Code Brown)
- Session studio with timed phases and debrief
- Log book plus Pro spectrogram / weekly brief
- Playbooks for public stalls, fiber, travel, and emergencies
- Pro tier (local demo unlock): unlimited chat, voice scripts, multi-throne profiles, cloud brain

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000. On a phone, add to home screen for the standalone shell.

Cloud coach is optional. If `AI_GATEWAY_API_KEY` or a Vercel OIDC token is present, Pro users can enable **Cloud brain** in Settings.
